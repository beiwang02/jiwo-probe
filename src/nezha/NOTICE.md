# Nezha theme visual reference

Jiwo's Nezha theme is an independent re-implementation with Jiwo components and data APIs.
Its page structure (header, greeting clock, four overview cards, round toggles, group switch,
sort pill, server cards and inline list), colour tokens and type scale follow the default
user frontend of Nezha Monitoring V1,
[hamster1963/nezha-dash-v1](https://github.com/hamster1963/nezha-dash-v1)
(Apache License 2.0, reference revision `40e73328a6a7880a7180e65e9f96aa174a5ae2b6`).

No source files, illustrations, logos, fonts or other assets from that project are bundled;
the layout was rewritten in plain React and CSS, and all data comes from the MiaoMiaoWuX
controller snapshot that the other Jiwo themes already use. Nezha and Nezha Dash are the
names of their respective projects; this theme is not affiliated with or endorsed by them.
